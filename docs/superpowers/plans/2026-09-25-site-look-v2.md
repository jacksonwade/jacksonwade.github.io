# kamai.uk Second Look Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the site's presentation with the approved Newsreader design, leaving the build pipeline untouched.

**Architecture:** The static build, the URL shape, the markdown renderer, RSS, the sitemap and the deploy workflow all stand. This plan swaps the typeface, rewrites the stylesheet, rewrites the two page templates, deletes the contents block and with it the site's only JavaScript, and adds a `year` field to the date formatter. Four of the five test files are untouched.

**Tech Stack:** Node standard library only, `node --test`, plain CSS, plain HTML. No dependencies, no `package.json`.

**Spec:** `docs/superpowers/specs/2026-09-25-site-look-v2-design.md`

## Global Constraints

- Use the absolute path `/opt/homebrew/bin/node`. Plain `node` recurses on an undefined nvm hook in non-interactive shells and appears to hang.
- No npm dependencies, no `package.json`. Tests are `node --test` with `node:assert/strict`.
- Must run on Node 20, which CI pins. Do not use APIs newer than Node 20.
- No em dashes or en dashes anywhere, in code, comments or copy.
- No comment blocks above code explaining what it does. Rare inline comments only, for a genuine subtlety. No comments in config files.
- Exact tokens, copied verbatim: `--bg: #12100e`, `--body: #ede8e0`, `--muted: #9a9188`, `--line: #2b241d`, `--accent: #cc785c`, `--code-bg: #1a1613`.
- Grain: `opacity: 0.14`, `mix-blend-mode: soft-light`, `position: fixed`, `baseFrequency='0.65'`, `numOctaves='4'`, 260x260 inline SVG.
- **No italics** except the `<em>` produced by `*emphasis*` in prose. **No underlines** anywhere. **No `text-transform: uppercase`** anywhere. Nothing drawn except the blockquote's left rule and the list bullets.
- Section heading over `posts/` reads "Writing", not "Blog". URLs stay `/blog/<slug>`.

## Review Focus

Failure modes the spec implies that a rewrite could easily drop. Each has its test pinned to the task that owns it.

1. An entry with no body must render its title and date and nothing else, for research entries as well as posts. The old `detailPage` fell back to the summary; that fallback must not survive. Task 5.
2. A title or summary containing `&`, `<` or `"` must stay escaped through markup that is being rewritten from scratch. Tasks 4 and 5.
3. An entry with no date at all must not emit an empty date element with its margin still applied. Tasks 4 and 5.
4. Every entry drafted, which is the site's state today, must still produce an index with the name, no section headings, and the ending. Task 4.
5. Front matter `links` must render somewhere. The old detail page put them under a subtitle that no longer exists, so a careless rewrite drops them silently. Task 5.

```js
export function formatDate(v) {
  if (v === undefined || v === null || v === '') return { display: '', sort: 0, iso: '', year: '' };
  const s = String(v).trim();

  const full = s.match(/^(\d{4})-(\d{2})-(\d{2})/);
  if (full && MONTHS[Number(full[2]) - 1]) {
    return {
      display: Number(full[3]) + ' ' + MONTHS[Number(full[2]) - 1] + ' ' + full[1],
      sort: Date.UTC(Number(full[1]), Number(full[2]) - 1, Number(full[3])),
      iso: full[1] + '-' + full[2] + '-' + full[3],
      year: full[1],
    };
  }
  const month = s.match(/^(\d{4})-(\d{2})$/);
  if (month && MONTHS[Number(month[2]) - 1]) {
    return {
      display: MONTHS[Number(month[2]) - 1] + ' ' + month[1],
      sort: Date.UTC(Number(month[1]), Number(month[2]) - 1, 1),
      iso: month[1] + '-' + month[2] + '-01',
      year: month[1],
    };
  }
  const year = s.match(/^(\d{4})$/);
  if (year) {
    return { display: year[1], sort: Date.UTC(Number(year[1]), 0, 1), iso: year[1] + '-01-01', year: year[1] };
  }
  return { display: s, sort: 0, iso: '', year: '' };
}
```

export function detailPage({ site, item }) {
  const { html: bodyHtml } = renderBody(parseBody(item.body));

  const links = (item.links || []).map(l =>
    '<a href="' + esc(l.url) + '" target="_blank" rel="noopener">' + esc(l.label) + '</a>'
  ).join('');

  const content =
    '<header class="top"><a class="brand" href="/">' + esc(site.name) + '</a></header>' +
    '<main class="wrap">' +
      '<article>' +
        '<h1 class="d-title">' + esc(item.title) + '</h1>' +
        (item.year ? '<p class="d-date">' + esc(item.year) + '</p>' : '') +
        (links ? '<div class="d-links">' + links + '</div>' : '') +
        '<div class="d-body">' + bodyHtml + '</div>' +
      '</article>' +
    '</main>' +
    footer(site, { home: true });

  return page({
    site,
    title: item.title + ' :: ' + site.name,
    description: item.summary || item.title,
    canonical: site.url + item.url,
    bodyClass: 'is-detail',
    content,
  });
}
